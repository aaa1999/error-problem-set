# 做题工作流：手机做题 → 推送 → 电脑导入错题

适合「平时在手机上刷题，回电脑上整理错题」的使用方式。清单随题库数据（data.json）一起同步，
不需要任何额外服务或文件搬运。

## 前提

- 手机（iOS）和电脑（桌面端）都连到同一台同步服务器（`backend/sync_server.py`，默认端口 8081），
  部署与地址填写见 [sync-protocol.md](./sync-protocol.md) 与 [../backend/README.md](../backend/README.md)
- 两端 app 均为 v0.8 及以上（支持做题 tab 与待导入清单）

## 第一步：手机上做题

1. 打开底部 tab「✍️ 做题」
2. 填写设置：
   - **文件夹名**：这批题将来导入错题本时归入的文件夹（按名称查找，没有会自动创建；留空 = 未分类）
   - **题数**：1–100（默认 100）
3. 开始做题：逐题选 **A / B / C / D**；做题过程中觉得某题值得收进错题本，点亮右侧 **⭐**
4. 做完点「完成作答，去对答案」：
   - 逐题手输正确答案，或用**批量导入**——粘贴每行「题号 + Tab + 答案」的文本
     （如 `1	A`，一行一条；分隔符兼容 Tab/空格/逗号），点「从文本填入」
5. 「完成比对」后是结果页：答对/答错统计、每题对错一目了然
6. 在「是否导入错题本」列表里**勾选要带回电脑的题**（答错和 ⭐ 默认勾上，可增减——错题不必非得导入）

## 第二步：存清单并推送（手机）

1. 结果页点「**存为待导入清单（推送后在电脑导入）**」——勾选的题（题号、你的答案、正确答案、⭐）
   连同文件夹名一起存进题库，手机本地不导入
2. 顶栏「☁ 同步」→ 推送（可勾选「记住此地址」）。清单随 data.json 上服务器，几 KB 秒传；
   图片差量上传与清单无关，不受影响

> 手机上也可以直接「导入勾选的 N 题」（在手机本地生成占位错题），
> 清单只是多了「拿回电脑慢慢补内容」的选择，两条路不冲突。

## 第三步：电脑拉取（桌面端）

1. 顶栏「☁ 同步」→ 切到「⬇ 从远程拉取」→「检查并预览」→「开始合并」
2. 清单作为数据的一部分合并进来（按 id 去重，重复拉取不会出现重复清单）

## 第四步：电脑导入错题

1. 打开顶栏「✍️ 做题」tab，设置页下方会出现「**来自手机做题的待导入清单**」：
   每份显示文件夹名、共几题、待导入题号与时间
2. 两个操作：
   - **「导入 N 题」**：在对应文件夹为每个题号生成占位错题——
     题干为「第 N 题（做题导入，待补充题目内容）」，解析里写批改记录
     （我选 X，正确答案 Y + 时间 + 来自手机清单）；完成后这份清单自动删除
   - **「丢弃」**：不要这份清单
3. 去「错题本」对应文件夹，逐题**编辑**补上真实题目内容、图片、选项——补完就是一道正式错题，
   复习、错误率、标签等一切照常

## 注意事项

- 清单存在 data.json 的 `pendingImports` 字段里，随现有同步/合并导入通道流转，服务器无需任何改动
- 手机推送后如果又改了主意：清单未导入前一直在电脑端待着，随时可「丢弃」
- 两端都是「拉取合并」语义：电脑导入清单生成的错题，之后手机再拉取会把它们合并回去（按题 id 去重），
  不会重复
- 做题会话本身（未存清单的）只保留在设备内存，重启 app 后重新开始；**存了清单的**会持久化并随同步流转
